# Interface: FrontmatterContentMap

Defined in: node\_modules/.pnpm/@types+mdast@4.0.4/node\_modules/@types/mdast/index.d.ts:227

Registry of all mdast nodes that can occur where [FrontmatterContent](../type-aliases/FrontmatterContent.md)
is expected.

This interface can be augmented to register custom node types:

```ts
declare module 'mdast' {
  interface FrontmatterContentMap {
    // Allow using toml nodes defined by `remark-frontmatter`.
    toml: TOML;
  }
}
```

For a union of all frontmatter content, see [RootContent](../type-aliases/RootContent.md).
