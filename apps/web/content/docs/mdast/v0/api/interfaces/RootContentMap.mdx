# Interface: RootContentMap

Defined in: [packages/mdast/src/index.ts:416](https://github.com/md2docx/md2docx/blob/main/packages/mdast/src/index.ts#L416)

Registry of all mdast nodes that can occur as children of [Root](Root.md).

> **Note**: [Root](Root.md) does not need to be an entire document.
> it can also be a fragment.

This interface can be augmented to register custom node types:

```ts
declare module 'mdast' {
  interface RootContentMap {
    // Allow using toml nodes defined by `remark-frontmatter`.
    toml: TOML;
  }
}
```

For a union of all [Root](Root.md) children, see [RootContent](../type-aliases/RootContent.md).
