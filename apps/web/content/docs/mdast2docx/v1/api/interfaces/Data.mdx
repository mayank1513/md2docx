# Interface: Data

Defined in: [packages/mdast/src/index.ts:179](https://github.com/md2docx/md2docx/blob/main/packages/mdast/src/index.ts#L179)

Info associated with mdast nodes by the ecosystem.

This space is guaranteed to never be specified by unist or mdast.
But you can use it in utilities and plugins to store data.

This type can be augmented to register custom data.
For example:

```ts
declare module 'mdast' {
  interface Data {
    // `someNode.data.myId` is typed as `number | undefined`
    myId?: number | undefined
  }
}
```
