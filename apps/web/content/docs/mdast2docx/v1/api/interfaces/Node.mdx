# Interface: Node

Defined in: [packages/mdast/src/index.ts:560](https://github.com/md2docx/md2docx/blob/main/packages/mdast/src/index.ts#L560)

Abstract mdast node.

This interface is supposed to be extended.
If you can use [Literal](Literal.md) or [Parent](Parent.md), you should.
But for example in markdown, a thematic break (`***`) is neither literal nor
parent, but still a node.

To register custom mdast nodes, add them to [RootContentMap](RootContentMap.md) and other
places where relevant (such as ElementContentMap).

For a union of all registered mdast nodes, see [Nodes](../type-aliases/Nodes.md).
