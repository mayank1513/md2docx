# Interface: RootContentMap

Defined in: node\_modules/.pnpm/@types+mdast@4.0.4/node\_modules/@types/mdast/index.d.ts:328

Registry of all mdast nodes that can occur as children of [Root](Root.mdx).

> **Note**: [Root](Root.mdx) does not need to be an entire document.
> it can also be a fragment.

This interface can be augmented to register custom node types:

```ts
declare module 'mdast' {
  interface RootContentMap {
    // Allow using toml nodes defined by `remark-frontmatter`.
    toml: TOML;
  }
}
```

For a union of all [Root](Root.mdx) children, see [RootContent](../type-aliases/RootContent.mdx).
